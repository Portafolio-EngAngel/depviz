# DepViz — Monorepo Dependency Graph Visualizer

Upload a ZIP of your repository and get an interactive, force-directed graph showing package dependencies, circular dependency cycles, and impact radius — in seconds.

## Stack

| Layer     | Technology                          |
|-----------|-------------------------------------|
| Backend   | Python 3.12, FastAPI, networkx      |
| Frontend  | Vanilla HTML, D3.js v7 (CDN)        |
| Container | Docker, Docker Compose              |

## Quick start

```bash
docker compose up --build
```

Then open [http://localhost:8004](http://localhost:8004) in your browser.

## How to use

1. **Prepare your ZIP** — archive your monorepo root (any structure works; nested `package.json` and `requirements.txt` files are discovered automatically).
2. **Upload** — drag-and-drop or click the upload area on the home page, then click **Analyze Repository**.
3. **Explore** — the interactive graph opens automatically:
   - **Click a node** to inspect its direct dependencies and dependents in the side panel.
   - **Hover a node** for a quick tooltip summary.
   - **Zoom and pan** with scroll + drag, or use the ±/reset buttons.
   - Red dashed edges indicate circular dependencies.

## Features

- **Circular dependency detection** — cycles are highlighted with red dashed edges and reported in the stats bar.
- **Impact radius** — node size reflects how many packages depend on it (in-degree); larger = higher blast radius.
- **Multi-ecosystem** — parses both `package.json` (npm) and `requirements.txt` (pip) in a single pass. Internal packages (those that own their own manifest) are coloured cyan; npm deps amber; pip deps violet.
- **Zoom + pan navigation** — D3 zoom with mouse wheel, touch pinch, and keyboard-friendly control buttons.
- **Node inspection panel** — click any node to see its dependency list and dependent list; click list items to jump to that node.
- **Max depth stat** — shows the longest dependency chain in the graph.

## Project structure

```
depviz/
├── backend/
│   ├── Dockerfile
│   ├── requirements.txt
│   └── app/
│       ├── main.py              # FastAPI app, CORS, static file serving
│       ├── routers/
│       │   └── graphs.py        # POST /graphs/analyze endpoint
│       ├── services/
│       │   ├── parser.py        # ZIP parsing, package.json + requirements.txt
│       │   └── graph.py         # networkx graph construction + analytics

├── docker-compose.yml
└── .gitignore
```

## API

| Method | Path              | Description                                      |
|--------|-------------------|--------------------------------------------------|
| GET    | `/`               | Upload UI (index.html)                           |
| GET    | `/graph`          | Visualization UI (graph.html)                    |
| POST   | `/graphs/analyze` | Accepts multipart ZIP, returns `GraphResult` JSON|
| GET    | `/health`         | Health check                                     |
| GET    | `/docs`           | Swagger UI (auto-generated by FastAPI)           |

## Environment variables

No required environment variables. The service binds to `0.0.0.0:8000` inside the container (mapped to `8004` on the host by Docker Compose).

## Development (without Docker)

```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
